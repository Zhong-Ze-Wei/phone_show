# 中国手机数据收集与整理项目

## 项目目标
收集中国手机市场的详细数据，特别是手机镜头型号、官方宣传内容等补充信息，以及国内手机媒体的技术资料，并整理成PDF供问答系统使用。

## 数据源
- 31du.cn: 手机CMOS传感器天梯图
- DXOMARK.cn: 专业手机相机评测
- GSMArena.com: 国际权威手机规格数据库
- 各品牌官方技术文档
- 行业分析报告

## 项目结构
```
choise_phone/
├── README.md                    # 项目说明
├── data/                        # 原始数据
│   ├── raw/                     # 原始抓取数据
│   ├── processed/               # 处理后数据
│   └── final/                   # 最终数据
├── docs/                        # 生成的PDF文档
│   ├── by_brand/                # 按品牌分类
│   └── by_category/             # 按类别分类
├── scripts/                     # 数据处理脚本
├── config/                      # 配置文件
└── logs/                        # 日志文件
```

## 数据收集范围
- 主要中国手机品牌：小米、华为、荣耀、OPPO、vivo、 OnePlus、iQOO、Realme等
- 时间范围：2024-2025年发布机型
- 数据类型：技术规格、传感器型号、官方宣传材料、评测内容

## 实施阶段
1. **阶段1**: 数据源内容抓取
2. **阶段2**: 数据标准化处理
3. **阶段3**: 补充信息收集
4. **阶段4**: PDF整理与生成
