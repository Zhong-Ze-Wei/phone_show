# 中国手机数据收集项目使用说明

## 项目概述

本项目专门用于收集中国手机市场的详细数据，包括：
- 手机镜头型号和技术规格
- 官方宣传材料和发布信息
- 专业评测网站的技术数据
- 传感器型号对照表

## 快速开始

### 1. 环境准备

```bash
# 安装依赖
pip install -r requirements.txt

# 创建必要目录
mkdir -p data/raw data/processed data/final docs/by_brand docs/by_category logs
```

### 2. 运行项目

```bash
# 完整流程（推荐）
python main.py --mode full

# 仅收集数据
python main.py --mode collect

# 仅生成PDF
python main.py --mode pdf

# 详细输出
python main.py --mode full --verbose
```

## 数据源说明

### 主要数据源
1. **31du.cn** - 手机CMOS传感器天梯图
   - 包含详细的传感器型号、尺寸、参数
   - 传感器排名和搭载机型信息

2. **DXOMARK.cn** - 专业相机评测
   - 详细的拍照评分和测试结果
   - 专业分析和对比

3. **GSMArena.com** - 国际手机数据库
   - 完整的技术规格
   - 发布时间和价格信息

### 次要数据源
- Phone888.cn - 手机规格搜索
- DeviceSpecifications.com - 设备规格
- 各品牌官方网站

## 输出文档说明

### 按品牌分类的PDF
每个手机品牌生成独立的PDF文档，包含：
- 品牌介绍和数据来源
- 各机型详细技术规格
- 传感器和摄像头配置
- 发布信息和价格

### 按类别分类的PDF
- **CMOS传感器汇总** - 所有传感器型号对照表
- **摄像头配置汇总** - 各品牌摄像头技术对比
- **技术趋势分析** - 行业发展趋势

### 汇总索引PDF
包含所有生成文档的索引和使用说明。

## 配置文件

`config/config.json` 包含：
- 数据源配置
- 目标品牌列表
- 收集规则和优先级
- 输出格式设置

可以根据需要修改配置文件来：
- 添加新的数据源
- 调整目标品牌
- 修改收集规则
- 自定义输出格式

## 使用建议

### 1. 日常使用
```bash
# 定期更新数据
python main.py --mode full

# 查看详细日志
tail -f logs/main.log
```

### 2. 自定义数据收集
修改 `config/config.json` 中的 `target_brands` 来添加或删除品牌。

### 3. 扩展数据源
在配置文件的 `data_sources` 部分添加新的数据源。

## 注意事项

1. **网络访问**：需要能够访问目标网站
2. **存储空间**：建议至少准备1GB存储空间
3. **运行时间**：完整流程可能需要30-60分钟
4. **法律合规**：仅收集公开信息，供学习研究使用

## 常见问题

### Q: 运行出现网络错误？
A: 检查网络连接，某些网站可能需要特殊访问方式。

### Q: PDF中文显示异常？
A: 确保系统安装了中文字体，程序会自动尝试使用系统字体。

### Q: 数据收集不完整？
A: 可以查看日志文件了解具体错误，部分网站可能有反爬机制。

### Q: 如何添加新的手机品牌？
A: 修改配置文件中的 `target_brands` 部分。
