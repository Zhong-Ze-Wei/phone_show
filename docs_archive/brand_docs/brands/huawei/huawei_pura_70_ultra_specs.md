# 华为Pura 70 Ultra 技术规格与官方资料

## 基本信息
- **品牌**: 华为 (Huawei)
- **型号**: Pura 70 Ultra
- **系列**: Pura系列
- **发布日期**: 2024年4月18日
- **上市时间**: 2024年4月29日
- **型号代码**: HBN-AL00
- **官方网站**: https://consumer.huawei.com/cn/phones/pura70-ultra/

## 核心技术规格

### 处理器与性能
- **芯片**: 麒麟 9010 (Kirin 9010)
- **制程**: 7nm
- **CPU架构**: 八核心处理器
  - 1x 2.3 GHz 泰山大核
  - 3x 2.18 GHz 泰山中核
  - 4x 1.55 GHz Cortex-A510小核
- **GPU**: Maleoon 910

### 存储配置
- **内存**: 12GB / 16GB LPDDR5X
- **存储**: 512GB / 1TB UFS 4.0
- **扩展**: 不支持存储卡扩展

### 外观设计
- **尺寸**: 162.6×75.1×8.4mm
- **重量**: 226g (含电池)
- **材质**:
  - 前面板: 玻璃
  - 边框: 铝合金
  - 后盖: 生态皮革 (硅聚合物)
- **颜色**: 黑色、白色、棕色、绿色
- **玻璃**: 第二代昆仑玻璃 (玄武钢化)
- **防护**: IP68防尘防水 (2米水深30分钟)

### 显示屏
- **类型**: LTPO OLED
- **尺寸**: 6.8英寸
- **显示区域**: 109.0 cm² (屏占比约89.3%)
- **分辨率**: 1260×2844像素 (~460 PPI)
- **色彩**: 10.7亿色, DCI-P3色域
- **刷新率**: 1-120Hz自适应刷新率
- **调光**: 1440Hz高频PWM调光
- **触控**: 300Hz触控采样率
- **亮度**: 2500尼特峰值亮度
- **显示技术**: ZREAL, HDR Vivid
- **保护**: 第二代昆仑玻璃

## 影像系统

### 后置三摄系统

#### 主摄像头
- **传感器**: 50MP
- **传感器尺寸**: 1英寸 (1.0"-type)
- **像素尺寸**: 1.22μm
- **光圈**: f/1.6-4.0 可变光圈
- **焦距**: 23mm等效 (广角)
- **对焦**: 双像素PDAF
- **防抖**: 传感器位移OIS
- **特色**: 伸缩镜头技术 (Retractable Lens)
