## 核心技术规格

### 处理器与性能
- **芯片**: Snapdragon® 8 Gen 3 Mobile Platform
- **制程**: 4nm功率效率制造工艺
- **CPU架构**:
  - 1x Prime core (X4-based), 最高3.3GHz
  - 3x Performance cores (A720-based), 最高3.2GHz
  - 2x Performance cores (A720-based), 最高3.0GHz
  - 2x Efficiency cores (A520-based), 最高2.3GHz
- **GPU**: Qualcomm® Adreno™ GPU

### 存储配置
- **内存**: 16GB LPDDR5X 8533Mbps
- **存储**: 512GB UFS 4.0

### 外观设计
- **尺寸**: 161.4×75.3×9.20mm
- **重量**: 219.8g
- **材质**: 素皮后盖 + 金属边框
- **设计特色**: 突出的摄像头模组, 环保素皮材质

### 显示屏
- **类型**: All Around Liquid Display WQHD+ AMOLED
- **尺寸**: 6.73英寸
- **分辨率**: 3200×1440, 522 PPI
- **刷新率**: 动态1-120Hz LTPO AdaptiveSync Pro
- **触控采样率**: 最高240Hz
- **面板**: 小米定制C8显示面板
- **亮度**:
  - HBM 1000尼特 (典型)
  - 3000尼特峰值亮度
- **显示技术**: Pro HDR显示, 支持UltraHDR
- **认证**: Dolby Vision®, HDR10+, 680亿色彩
- **色域**: DCI-P3 TrueColor显示
- **护眼**: 自适应色彩, 原色PRO, 自适应阅读模式, 阳光模式
- **调光**: DC调光 / 1920Hz PWM调光
- **认证**: TÜV Rheinland低蓝光(硬件解决方案)认证, 闪烁友好认证, 生理节律友好认证
- **玻璃**: 小米Shield Glass
