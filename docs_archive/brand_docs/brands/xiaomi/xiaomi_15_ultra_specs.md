# 小米15 Ultra 技术规格与官方资料

## 基本信息
- **品牌**: 小米 (Xiaomi)
- **型号**: 15 Ultra
- **发布日期**: 2024年底
- **官方网站**: https://www.mi.com/global/product/xiaomi-15-ultra/

## 核心技术规格

### 处理器与性能
- **芯片**: Snapdragon® 8 Elite Mobile Platform
- **制程**: 3nm制造工艺
- **CPU**: 2 x Prime Core, 最高4.32GHz + 6 x Performance Core, 最高3.53GHz
- **GPU**: Adreno™ GPU
- **AI**: Qualcomm AI引擎

### 存储配置
- **内存**: 16GB LPDDR5X 8533Mbps
- **存储**: 512GB / 1TB UFS 4.1
- **可选配置**: 16GB+512GB | 16GB+1TB

### 外观设计
- **尺寸**:
  - 黑色/白色: 161.3×75.3×9.35mm, 226g
  - 银色镀铬: 161.3×75.3×9.48mm, 229g
- **材质**: 高强度铝合金边框 + 小米Shield Glass 2.0

### 显示屏
- **尺寸**: 6.73英寸 WQHD+ AMOLED
- **分辨率**: 3200×1440, 522 PPI
- **亮度**: 3200尼特峰值亮度
- **刷新率**: 1-120Hz自适应
- **触控采样率**: 最高300Hz
- **色彩**: DCI-P3色域, 680亿色深
- **调光**: 1920Hz PWM调光 / DC调光
- **认证**: HDR10+, Dolby Vision®, TÜV Rheinland低蓝光认证
