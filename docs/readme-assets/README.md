# README 横幅

`banner-light.svg` 和 `banner-dark.svg` 为同一布局的浅色、深色版本，尺寸均为 1280 × 360。README 可使用 `<picture>` 按 `prefers-color-scheme` 选择版本，并将整个图片链接到 <https://zhong-ze-wei.github.io/phone_show/>。

横幅仅包含本地矢量图形与文本，不包含脚本、外部图像、外部字体或 `foreignObject`。右侧手机和比较轮廓是品牌插画，不代表真实型号、参数或产品截图；实际产品截图继续使用 `docs/ui-reference/` 中已有图片。

维护时同步修改两版文案和图形位置，仅使用不同主题配色。字体优先使用系统已有中文字体；无需安装依赖或生成图片。
