# 并行查看历史界面

## 版本身份

当前手机筛选版默认运行在 `http://127.0.0.1:8501/`。本仓库能完整恢复运行的最早提交是 `958741d`，日期 **2026-10-04**，这是当时依据旧截图重建的版本，不能称作几个月前的原版。

真实原版截图来自 `Get_Phone` 的 **2025-10-15、2025-10-18** 提交。原项目采用 Flask、HTML/CSS/JavaScript 和 MySQL；父仓库仅保存网页子仓库指针，没有完整模板、路由或服务源码。2026-10-06 用已有 GitHub 登录重新检查两个手机仓库：认证正常，但四个旧指针均返回 `No commit found for SHA`；远程分支、本地模块与对象库也没有对应源码。具体来源见 [原界面核查](UI_RESTORE.md) 和 [项目恢复记录](RECOVERY.md)。取得原子仓库源码后才能运行真正的 2025 原版。

## 启动对照

保持当前版运行，在另一个终端执行：

```powershell
uv run --no-sync python scripts/run_historical_preview.py
```

- [2026-10-04 可运行恢复版](http://127.0.0.1:8502/)：预算留空时当时的图库不加载，输入预算如 8000 即可操作。
- [2025 原版截图与两版入口](http://127.0.0.1:8502/history/)：查看原手机工作台、拖拽和顾问展开的真实截图；图片中的控件不能操作。
- [版本与资料副本信息](http://127.0.0.1:8502/api/preview-info)：核对提交、日期、数据来源和数量。

可用 `--port 8503` 换一个空闲端口。终端按 `Ctrl+C` 停止此预览，不影响 8501。若已在后台运行，先查对应端口及进程命令，确认是 `scripts/run_historical_preview.py --serve` 再停止该进程。

脚本使用独立、detached 的 Git worktree，位置 `logs/historical-preview/958741d/`，不切换当前开发目录的分支。Python 和前端依赖分别由该提交的 `uv.lock`、`package-lock.json` 固定；虚拟环境与构建产物也在历史目录中。首次需要 Git、uv、Node/npm，并会安装依赖和构建原提交的前端。运行目录和日志被 Git 忽略。

## 数据兼容的实际范围

**当前 SQLite 的存储结构可供这份 2026-10-04 恢复版读取，已实际验证。** 每次启动前，脚本通过只读 SQLite 连接，将当前数据库备份成历史运行目录中的独立副本；原始记录、逐字段来源、报价核验时间、清洗版本、产品 ID 和图片修复保留。它不会重新导入 Excel、重清洗或访问网站。资料缺失时应先按根 README 还原当前库。

旧版能显示手机卡片、来源、参数、详情及比较，但保留其原来的界面与后端逻辑：必填预算、默认至少 256GB、加权分数、最多 60 个推荐型号和三台对比。它没有后来修复的完整目录搜索、容量切换或新版官网通用参数合并；因此“能读取新库”不等于具有新版全部功能，也不等于它显示的少量结果就是数据库全部机型。旧 MySQL／Flask 的直接兼容性尚未验证，因为原源码未恢复。

旧版 `POST /api/sync` 被关闭，返回 409，防止旧采集／清洗策略修改预览资料。需要新资料时在 8501 更新，再停止并重启历史预览，重新取得副本。当前数据库始终不传给旧进程；历史副本的改动不会回写当前库。

AI 使用当前项目的 AIPing 配置，仅在进程内读取 `.env` 中的 `AIPING_` 字段，不复制密钥文件。浏览、打开顾问和查看截图不调用模型；用户明确发送问题仍会请求模型。不同端口有各自的浏览器本地存储，收藏与聊天保存不会自动混用。

## 本次验收

已验证 8501 与 8502 同时运行，加载不同的前端构建；历史服务及依赖的实际导入路径均属于历史 worktree 的独立 uv 环境。当前库和历史副本均含 **4,429 条配置、5,793 条原始快照及 795 条图片修复**。全部规范记录的 `id / record_json / updated_at / cleaning_version` 逐项相等，原报价和来源时间没有刷新。旧更新入口返回 409；验收没有真实模型调用。

`npm run build` 与 `npm test` 通过：366 项 Python、46 项前端测试。20 项实际浏览器与资料核对检查覆盖原图逐字节一致、手机版截图对照布局、旧版预算筛选、真实 ID 的详情和两机比较、打开顾问零模型请求、当前版持续运行、端口间存储隔离以及三张数据表全部记录一致。完整本机证据在忽略的 `logs/historical-preview-browser.json`，桌面与展开顾问截图保存在 `logs/historical-rebuild-desktop.png`、`logs/historical-rebuild-advisor.png`。
