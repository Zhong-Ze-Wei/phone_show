# 挑一部 · 选购工作台

前端是 React + TypeScript + Vite，生产版本由项目的 FastAPI 服务提供，默认地址 `http://127.0.0.1:8501/`。所有资料来自同源 `/api`，API 密钥只保存在后端。

## 本地开发

在项目根目录启动开发用后端：

```powershell
uv run python -m phone_assistant.server --port 8502
```

在本目录运行：

```powershell
npm ci
npm run dev
```

Vite 的 `/api` 请求代理到 `127.0.0.1:8502`。

## 验证与构建

```powershell
npm test
npm run build
```

构建产物位于 `dist/`。根目录启动脚本会先构建前端，再启动生产服务。

## 交互与数据口径

- 首页最高预算留空，不发送推荐请求，也不预设 4000 元。填写正数或点击预算档后开始推荐；清空、无效预算与重置会清除旧推荐、对比和明确选机上下文。预算不自动保存，聊天和已完成对话保留，元数据、搜索条件、收藏和资料更新仍可使用。
- 预算、用途、品牌、系统、容量、便携与型号检索提交给后端规则筛选，输入变化防抖 250ms，旧请求自动取消。
- 默认“综合推荐”按需求匹配 75%、预算余量 10%、上市时效 10%、主流品牌 5% 排序；一年内机型获得更多时效加分。可以切换新机优先、需求匹配与价格排序。卡片区分综合推荐分和需求匹配，并显示时效、品牌策略依据，两类分数都不是实测榜单。
- “考虑二手”仅表示二手机型参考，不因上市较新加分；当前参考价仍来自新机资料，没有二手行情、库存、成色或保修信息。历史资料开关独立保留，不会因二手场景自动启用。
- 参考价保留逐字段来源与采集日期。历史导入或超过 30 天的报价标记为历史价；采集日期未知的报价明确显示日期未知。
- 未知参数显示“待核实”，未知支持状态与“不支持”分开。原始参数仍可展开查看每个字段的来源。
- 暗色工作台参照项目 Git 历史截图重建，原子仓库源代码未取回，详见根目录 `docs/UI_RESTORE.md`。桌面分为约 70% 手机图库与约 30% 独立选择、对比面板；1600px 为三列图库，更宽屏为四列。卡片以固定 4:3 的真实来源图片为主，名称、价格、规格和对比动作常驻，长政策理由移到预览的可展开依据。
- 点击图片或使用键盘选择只更新当前手机预览，不隐式加入对比。预览默认当前返回的第一候选，选择按本轮请求和推荐/收藏视图隔离；预算、品牌等条件变化后立即隐藏旧推荐预览。右侧显示大图、规格、来源和详细资料入口，再独立提供三机对比与顾问。手机端在筛选后显示可折叠预览，单列图卡与底部对比操作条保留。
- 新品资料放在推荐后的折叠补充区，无候选时自动展开，仍能查看超预算机型并调整预算。
- 收藏只保存在当前浏览器的 `localStorage`。对比最多三部手机，可使用 HTML5 拖拽投放右侧整块区域的预览、文字或空白，也可用卡片按钮和键盘加入、移除。拖拽卡片倾斜透明，整个右栏蓝色高亮；外部文字不会被当成手机加入。每次打开对比都从后端读取最新资料、按当前条件重新评分；使用原生 `dialog` 处理焦点、Tab 与 Escape。
- 分页只切换本次返回的同一推荐名单，默认 20 项，也可选择 40/60 项；同时标注符合条件总数与实际展示候选数量，不把已返回数量当成全库完整覆盖。
- 桌面 AI 球切换约 1/3 左侧图库与 2/3 右侧聊天工作区，关闭回到 70/30 大图预览布局；聊天开启时右栏任意位置仍可投放比较。手机端通过底部操作条打开可关闭的全屏聊天，不用圆钮遮挡正文。预算留空也可打开本地欢迎界面，打开、角色切换、快捷问题填入、保存和加载都不调用模型。
- 五种顾问角色支持连续追问。只有发送按钮或 Ctrl/⌘ + Enter 向 `/api/chat` 发出请求，按真实 SSE 的 `context/delta/done/error` 流显示；每条回答独立保留当时机型与完整来源编号，正文 `[n]` 可打开对应来源。停止、关闭、换条件会取消旧流，取消、错误与截断回答不会进入模型历史，最多携带最近六轮完成问答。
- 聊天的“本次预算”（ARIA 标签“聊天最高预算”）显式同步页面预算，不从 AI 文字推断或自动修改。从详情或对比面板明确咨询时使用那个目标；普通开球优先当前对比机型，其次本轮主动点击预览或详情的机型。增删对比或重新从球打开清除明确咨询覆盖；默认第一张预览不算用户明确选机，无选择时由后端按当前条件找真实候选。
- 会话只在点击保存后写入本浏览器 `pick-a-phone.chat.v1`，保留一份、最多 40 条消息、整体 JSON 上限 100 万字符；保存与加载采用相同大小限制。加载严格校验格式，将保存时尚在响应的消息标成已停止。加载只恢复对话与顾问角色，不恢复预算、筛选或比较列表。关闭再开保持本页对话，清空不会删除已保存会话。`/api/explain` 后端接口继续保留。
- “更新资料”调用后台采集与清洗任务，关闭进度窗口不终止任务。质量面板展示实际覆盖、失败和待核验项目，部分成功不会被显示为全部收齐。
- 产品图片直接使用来源链接；图片缺失或加载失败显示“暂无来源图片”，不会虚构商品图。失败状态只作用于对应 URL，更新为新的来源图片地址后会重新尝试加载。
- 手机端采用单列并保证型号、规格和操作文字可读，平板、桌面保持多列密度；已选对比显示底部固定操作条。设置 `prefers-reduced-motion: reduce` 时关闭过渡与动画。
