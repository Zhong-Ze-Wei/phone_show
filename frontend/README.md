# 挑一部 · 选购工作台

前端使用 React + TypeScript + Vite，生产版本由 FastAPI 提供，默认地址 `http://127.0.0.1:8501/`。所有 API 同源，模型密钥只在后端。现行筛选交互更新日期：2026-10-06。

## 本地开发

项目根目录启动开发后端：

```powershell
uv run python -m phone_assistant.server --port 8502
```

在本目录运行：

```powershell
npm ci
npm run dev
```

Vite 将 `/api` 代理到 `127.0.0.1:8502`。生产构建与测试：

```powershell
npm test
npm run build
```

产物位于 `dist/`；根目录启动脚本先构建，再启动生产服务。

## 筛选与配置

- 首页预算为空、容量不限，可以立即浏览与搜索，不默认填金额。品牌、系统、容量、搜索词、金额和资料范围提交给 `/api/filter`；条件变化取消旧请求，旧结果不会冒充当前结果。
- 图库只筛选和排序，不计算或显示推荐分、匹配分、品牌或新机加分。只提供上市时间、价格升序、价格降序，默认上市时间。用途偏好在右侧顾问中表达，不改变图库或发起筛选请求。
- 空预算可查看近期、有当前上市证据的资料，即使具体报价待核实。设置金额上下限后需要该配置的独立近期报价，未知价不以零元、起价或其他容量价格通过。历史资料与二手机型参考分别标清，二手模式不产生二手行情。
- 型号搜索可查阅完整已存目录，历史、未来上市、旧报价、超预算等附状态说明。符合条件的家族不截断为评分前 60；前端分页用于浏览同一份完整响应。
- 一个型号一张卡，卡内保留真实 RAM／存储配置；没有具体容量的官网通用记录不计成额外配置。默认代表为当前条件内较低已知参考价的配置。
- 切换配置从 `/api/phones/{id}/variants` 读取真实记录、来源与条件状态，主卡、预览、详情、收藏、拖拽和明确顾问目标使用所选 ID。已加入对比的旧配置继续保留；条件变化隔离旧配置请求。
- 点击图片或键盘选择只更新预览，不隐式加入对比。图卡以真实来源大图为主，名称、价格、规格和独立对比动作常驻；缺图显示“暂无来源图片”，未知参数显示“待核实”。
- 对比数量不限，通过按钮、键盘或拖到整个右栏加入，按实际 ID 去重。打开比较时通过 `/api/compare` 重读全部所选资料和当前条件提示，不重算用途或综合分。参数表横向滚动，原生 `dialog` 处理焦点、Tab 与 Escape。
- 收藏保存在当前浏览器的 `localStorage`。资料、价格与图片保留原来源和核验时间，原始字段可以展开查阅；界面不会把来源参考价称为成交价或库存。
- 桌面维持左侧图库、右侧预览与比较；窗口收窄时按图库实际宽度增加密度，仍能浏览与拖拽。真正手机宽度使用单列图卡和底部操作条。开启减少动态效果设置时关闭动画和过渡。

## 顾问与资料更新

- AI 球打开右侧连续聊天，左侧仍能浏览；关闭后保留本页聊天。打开面板、换角色、设置用途、快捷填入、保存或加载都不调用模型。
- 五种角色只改变分析角度。发送或 Ctrl/⌘ + Enter 才向 `/api/chat` 请求，使用实际 SSE 的 `context/delta/done/error`。事实、字段来源和警告交给模型，不附固定规则分。
- 明确从详情或比较咨询时，使用全部真实选中 ID；普通开球优先对比，其次主动选中的预览或详情。没有主动选机时，后端取当前条件前三台控制上下文，不称它们是分数前三名。
- 顾问预算显式同步主预算，不从自然语言自动推断。用途只用于用户发送的分析。停止、关闭或变更事实条件会取消旧流；取消、报错和截断的回复不进入完成历史，每轮保留自己的完整来源编号。
- 会话只有点击保存才写入 `pick-a-phone.chat.v1`，最多 40 条消息、100 万字符。加载恢复文字与角色，不恢复预算、筛选和比较，也不调用模型。`/api/explain` 保留为手动分析入口。
- “更新资料”启动后台采集与清洗；关闭进度窗口不停止任务。质量面板展示真实覆盖、失败和待核验项，不能把部分完成显示为收齐全部手机。

筛选规则见根目录 [筛选策略](../docs/RECOMMENDATION_STRATEGY.md)，连续聊天与来源规则见 [AI 顾问](../docs/AI_CHAT.md)。
